  <h3>💡 Por que usei cada tecnologia?</h3>
  <ul>
    <li><strong>HTML5:</strong> para montar toda a estrutura das seções do portfólio (Sobre mim, Experiências, Formação, Projetos e Contato).</li>
    <li><strong>CSS3:</strong> para criar o visual do site, deixar bonito, organizado e responsivo em diferentes telas.</li>
    <li><strong>JavaScript:</strong> para interações da página, como menu mobile, animações e comportamento dos botões.</li>
    <li><strong>TypeScript:</strong> para deixar o código JavaScript mais seguro e organizado, ajudando a evitar erros.</li>
    <li><strong>Node.js:</strong> para rodar o ambiente de desenvolvimento e os comandos do projeto (npm).</li>
    <li><strong>Vite:</strong> para iniciar o projeto rápido, atualizar em tempo real no desenvolvimento e gerar o build de produção.</li>
  </ul>
